# CULL downloads

Installers and the update manifest for [CULL](https://github.com/OliverSogaard), keyboard-fast culling for RAW photos. The application source is private; this repository only carries what the installed app and the download page need.

- `latest.json` — the updater manifest the app reads
- `CULL_<version>_x64-setup.exe` — Windows installer
- `CULL_<version>_aarch64.dmg` — macOS (Apple Silicon)

Each release replaces the previous files; older versions are not kept here.
